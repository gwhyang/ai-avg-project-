# 小游戏试玩

在 Godot 中打开 `res://Minigames/PrototypeHub.tscn`，按 F6 运行当前场景。大厅包含剧本总览中的八个主题小游戏；点击任一项目进入，完成后可重试或返回大厅。主场景 `res://Scenes/Main.tscn` 和剧情 Timeline 不调用这些场景。

所有结果只在当前试玩场景显示，不读取或修改 Dialogic 变量。主线现有小游戏占位和自动发放首次成功奖励的逻辑保持原样。接入主线时，应将真实结果替换对应占位与自动奖励，避免重复计分。

## 待定规则

- 批文解读首次成功为顺伯信任 +15，重试成功按剧本的“一半”显示 +7.5；正式接入整数关系值前需要确定取整规则。
- 送批路线没有标准答案。官道只显示盘查和批银损失风险，不擅自确定损失概率或数额；山道显示体力消耗，不新增体力变量；水路预览顺伯信任 +5。
- 批封辨识的剧本要求检查日期，但候选批封没有日期信息；试玩只依据剧本写出的款项、落款与印章判定。
- 批文还原没有数值奖励。原剧本画了八个空格，但三个候选句均为七字，试玩界面按答案长度画七格。
- 尾声展厅的扫码与接力写批是附录列出的第九项互动，尚缺二维码目标、故事数据和数字批封规则，不属于当前八项主题小游戏。
