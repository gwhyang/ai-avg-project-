# 《一纸千山》UI、道具及小游戏切图资源包

- 前端使用路径：`assets/ui/{panels,icons,buttons,items,widgets,papers}/`
- 图片统一为 PNG，使用透明通道。
- 文件名全部小写英文字母、数字与下划线。
- 切出素材已自动去除周围空白并保留少量安全边缘。
- 命名为 `panel_001.png`, `icon_001.png`, `item_001.png` 等，不贸然猜测细节名称。
- `production_notes/manifest.json` 记录每个文件对应的原始图、边界框、尺寸。
- `reference_sheets/` 保留重命名原图用于核对，**不建议作为前端切片直接引用**。
- 这些图片是AI视觉素材，个别贴近相邻元素的细部可能有粘连、碎片或生成瑕疵，导入时需要核验。
- 前端若要制作九宫格拉伸按钮/对话框，需另设 nine-slice 参数；不要直接不等比拉伸整张位图。
- 当前切图按视觉图元分割，并未按六个小游戏的逻辑状态配置为标准套装；用途需开发时映射。

类别：
- `panels`: 大对话框、信息面板、边框等
- `icons`: 导航、功能图标、指示器等
- `buttons`: 按钮不同视觉状态、卷轴式面板等
- `items`: 侨批、印章、银两、算盘、卷轴、油灯、船、铜钱、地图等
- `widgets`: 选择框、进度条、锁、标记等
- `papers`: 纸页、残片、标签、拼图元素等
