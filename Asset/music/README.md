# 配乐对应

八首原始 MP3 已通过 Dialogic 原生 `audio music` 事件接入主线；不需要另外开启播放器。

| 场景 | 文件 | 播放音量 |
| --- | --- | --- |
| 序章 | `【淡入】序章音乐.mp3` | −8 dB |
| 第一章 | `【淡入】第一章音乐.mp3` | −12 dB |
| 第二章、《救国批》、《未竟》 | `【淡入】第二章音乐+《救国批》+《未竟》.mp3` | −8 dB |
| 第三章送批、遇袭 | `【淡入】第三章音乐.mp3` | −13 dB |
| 第三章阿妹求助、是否挪用批银及两种结果 | `第三章（阿棠是否要给阿妹钱抉择）.mp3` | −10 dB |
| 第四章 | `【淡入】第四章音乐.mp3` | −12 dB |
| 第五章与战后去留选择 | `【淡入】第五章音乐.mp3` | −11 dB |
| 《批归》《守信》《下南洋》、父亲来信待补段、现代终章及尾声 | `《批归》《守信》《下南洋》+所有结局统一汇入.mp3` | −12 dB |

每首循环播放，切换时前后两曲交叉淡化 1.5 秒。音量根据源文件电平做小幅补偿，原始音频没有重编码或裁剪。时间线中的 `volume` 是可调播放增益。

同曲切换（如《守信》转《下南洋》、三个普通结局进入现代终章）会检测正在播放的文件并沿用播放进度；《救国批》《未竟》进入现代终章时才换统一结局曲。隐藏结局、普通结局和展厅尾声之间继续播放，不重复从头开始。最后一段结束时淡出 1.5 秒，再返回标题；快进会按 Dialogic 原有行为缩短等待，因此可能提前结束淡出。

配乐事件紧跟各段入口标签，因此从 Dialogic 编辑器直接运行章节也能播放。使用原生 music 通道，随 Dialogic 暂停、清理和存档；读档恢复遵循插件原有行为，会恢复曲目但不保存秒级播放位置。

修补了 Dialogic 音频清理：音量动画随播放器释放，结束剧情时同时清理尚在淡出的旧曲，避免切歌中途返回菜单或快进结束时残留音乐、访问已释放播放器。
